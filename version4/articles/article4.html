使用Electron制作桌面应用

 2025/12/21    芒蹊   # 技术

0.介绍

Electron是一个使用 JavaScript、HTML 和 CSS 构建桌面应用程序的框架。 嵌入 Chromium 和 Node.js 到二进制的 Electron 允许您保持一个 JavaScript 代码代码库并创建在Windows上运行的跨平台应用 macOS和Linux——不需要本地开发经验。

简而言之，使用Electron可以让你只使用前端三件套就能构建一个桌面应用，而不需要C、C++或Python知识。

官方文档

1.准备

基本的前端技术，一个文本编辑器（推荐使用Microsoft VS Code），以及Node.js

2.开始

Electron 应用基于 npm 搭建，以 package.json 文件作为入口点。首先创建一个文件夹（这里以my-electron-app为例），然后在其中执行 npm init ，根据引导进行初始化项目。可以使用Windows默认的 命令提示符或PowerShell 命令行工具。这将创建并配置package.json。

cd my-electron-app
npm init

然后，将 Electron 安装为您项目的 devDependencies，即仅在开发环境需要的额外依赖。

npm install electron --save-dev

完成以后，目录中的package.json应当形如：

{
    "name": "my-electron-app",
    "version": "1.0.0",
    "description": "Hello World!",
    "main": "main.js",
    "scripts": {
        "test": "echo \"Error: no test specified\" && exit 1"
    },
    "author": "Jane Doe",
    "license": "MIT",
    "devDependencies": {
        "electron": "23.1.3"
    }
}

在根目录中创建main.js，这将控制主程序(main process)，它运行在 Node.js 环境里，负责控制应用的生命周期、显示原生界面、执行特殊操作并管理渲染器进程 (renderer processes)。

console.log('Hello from Electron! ')

要执行这个脚本，需要在 package.json 的 scripts 字段中添加一个 start 命令，内容为 electron . 。 这个命令会告诉 Electron 在当前目录下寻找主脚本，并以开发模式运行它。

...
"scripts": {
  "start": "electron .",
  "test": "echo \"Error: no test specified\" && exit 1"
}
...

最后，在终端中执行以下命令，来运行脚本。

npm run start

若运行正常，终端应该输出：

Hello from Electron!

3.装载网页

接下来，将制作好的web页面装载至Electron应用中。

编辑html页面。以index.html为例：

<!DOCTYPE html>
<html>
    <head>
        <meta charset="UTF-8" />
        <title>My first Electron app</title>
    </head>
    <body>
        <h1>Hello from Electron renderer!</h1>
    </body>
</html>

在main.js加入以下脚本：

const { app, BrowserWindow } = require('electron') // 导入Electron模块

const createWindow = () => {
    const win = new BrowserWindow({ // 窗口预设
        width: 800,
        height: 600,                // 窗口大小
        x: 500,                     
        y: 200,                     // 窗口位置
        autoHideMenuBar: true       // 隐藏菜单栏
    })
    win.loadFile('index.html')      // 装载html文件
}

app.whenReady().then(() => {
    createWindow()                  // 创建窗口
})

运行 start 命令，桌面上将出现一个包含网页内容的窗口。
