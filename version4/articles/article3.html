1.单页应用

1.1.介绍

单页应用（SPA, Single Page Application），是一种 Web 应用架构模式。它的核心思想是： 整个网站只有一个 HTML 页面，用户在浏览不同内容时，不会重新加载整个页面，而是通过 JavaScript 动态地更新页面内容。

在传统的 MPA（多页应用）中，每次点击链接都会重新向服务器发送请求并加载一个新的页面。而在 SPA 中，仅在初次访问时加载 HTML、CSS、JS，之后所有内容变化都通过 JavaScript 控制，用户在跳转页面时不会引发整个页面刷新。

例如，当用户访问 home 页面时，SPA 会加载对应组件；而点击跳转 about 页面时，SPA 只会在当前页面中更新部分内容，浏览器地址栏会改变，但整个页面不会重新加载。

1.2.本站实现

以加载文章列表为例。

文件夹结构：

root
|index.html         // 主页
|articles           
 -articles.json     // 存放文章列表
 -article1.html     // 文章内容
|app.js             // js文件

index.html

<div class="article-list">
    <!-- 将在此处加载文章列表 -->
</div>

articles.json

[
    {
        "artiID" : "1",
        "title" : "我的文章标题", 
        "href" : "/articles/article1.html",
        "time" : "2025/12/15", 
        "author" : "芒蹊",
        "tag": "标签", 
        "tagNum": "1",
        "preview" : "文章预览，显示在列表中"
    }
]

app.js

// 加载文章列表
async function loadArticleList() {
    try {
        // 使用fetch获取文章列表
        const response = await fetch('/articles/articles.json');
        const articleList = await response.json();
        const container = document.querySelector(".article-list");

        // 根据列表内容生成元素
        articleList.forEach(list => {
            const listElement = document.createElement('div');
            listElement.className = 'article-list-item';
            listElement.dataset.artiId = `${list.artiID}`;
            listElement.innerHTML = `
            <div>${list.time} ${list.author} ${list.tag}</div>
            <div>${list.title}</div>
            <div>${list.preview}</div>
            `;
            container.appendChild(listElement);
        });
    } catch (error) {
        console.error(error);
        document.querySelector(".article-list").innerHTML = "加载文章列表失败" + error;
    }
}
// DOM加载完成后加载文章列表
document.addEventListener('DOMContentLoaded', loadArticleList);

2.移动端适配

2.1.原理

在version1和2版本中，我采用的方案是另外制作一个mobile页面，该页面的css样式专为移动端设计。这导致每次更新页面都需要改动多个文件，且跳转加载需要时间。

version4（当前）版本则是采用另一个方案，即电脑和手机端都使用同一个页面，通过修改css变量的方式来更改样式布局。

2.2.实现

在style.css文件中存储css变量。例如：

:root {
    --start_btn_width: 15vw;
    --box_width: 20vw;
    --box_left: 5vw;
    --page_width: 60vw;
    --padding_top: 10vh;
}

在js文件中，识别当前用户是否使用移动端设备。

在version1和2版本中，我使用获取浏览器标识的方法：

// 都是从网上复制粘贴来的，我也不知道原理是什么（小声
var deviceFlag = 1;
var thisOS = navigator.platform;
var os = new Array("iPhone", "iPod", "iPad", "android", "Nokia", "SymbianOS", "Symbian", "Windows Phone", "Phone", "Linux armv71", "MAUI", "UNTRUSTED/1.0", "Windows CE", "BlackBerry", "IEMobile");
var check = navigator.appVersion;

function checkDevice() {
    deviceFlag = 1;
    for (var i = 0; i < os.length; i++) {
        if (thisOS.match(os[i])) {
            deviceFlag = 2;
        }
    }
    if (navigator.platform.indexOf('iPad') != -1) {
        deviceFlag = 2;
    }
    if (check.match(/linux/i)) {
        if (check.match(/mobile/i) || check.match(/X11/i)) {
            deviceFlag = 2;
        }
    }
    Array.prototype.in_array = function (e) {
        for (i = 0; i < this.length; i++) {
            if (this[i] == e)
                return true;
        }
        return false;
    }
}

而在当前版本中，我将窗口宽高比小于1.2的页面视为移动端页面。

var vw = document.documentElement.clientWidth;
var vh = document.documentElement.clientHeight;
var is_mobile = false;

if ((vw / vh) <= 1.2) {
    is_mobile = true;
}

判断为移动端页面后，修改css变量以适应移动端的界面。

const root = document.querySelector(':root');
root.style.setProperty('--start_btn_width', '40vw');
root.style.setProperty('--box_width', '80vw');
root.style.setProperty('--box_left', '10vw');
root.style.setProperty('--page_width', '70vw');
root.style.setProperty('--padding_top', '7vh');
