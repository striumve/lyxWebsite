nginx服务器+Node.js后端配置

 2026/03/29    芒蹊   # 技术

0.准备

这里以Windows系统为例。首先安装所需的软件或环境：Node.js，nginx

1.配置Node.js

在网站根目录下新建app.js文件，写入以下内容

const http = require('http');

const server = http.createServer((req, res) => {
    const url = new URL(req.url, `http://${req.headers.host}`);
    res.statusCode = 200;
    res.setHeader('Content-Type', 'text/plain');
    // 在此处处理后端服务
    res.end('Hello World');
});

const port = process.env.PORT || 3000;   // Node.js默认监听端口为3000
server.listen(port, () => {
    console.log(`Server running on port ${port}`);
});

在终端中打开该根目录，运行Node.js

node app.js

2.配置反向代理

在nginx.conf中加入以下配置

location /api/ {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}

这可以把所有以hostname/api/开头的请求转交给Node.js来处理，此处即由app.js处理。

3.设置开机自启动

在Windows环境中，可以使用任务计划程序来配置开机自启动。使用快捷键Win + R打开运行框，输入taskschd.msc并回车，打开任务计划程序窗口。

点击“创建基本任务”，按照提示操作：输入任务名称，设置任务运行时间（计算机启动时），选择类型为“启动程序”，然后选择nginx.exe。

对于Node.js，需要使用pm2进程管理器：

npm install pm2 -g

-g参数意味global全局安装。接下来，app.js所在目录中打开终端，输入以下命令

pm2 start app.js
pm2 save
pm2 startup

对于Windows系统，无法使用startup命令来设置开机自启动。我们仍然使用任务计划程序，选择启动程序为C:\Users\user\AppData\Roaming\npm\pm2.cmd即可。
